# fa-bidi-fix

متن‌های فارسی/انگلیسی مخلوط، در رندرکننده‌های LTR درهم‌ریخته دیده می‌شوند. این پلاگین مشکل را از دو طرف حل می‌کند:

- **هوک `SessionStart`**: در شروع هر نشست، قواعد نگارش دوجهته (`hooks/bidi-rules.md`) به دستیار تزریق می‌شود تا پیام‌های بعدی ذاتاً سالم نوشته شوند — توکن‌های لاتین داخل بک‌تیک، علائم فارسی، ارقام فارسی، و حداقل جابه‌جایی جهت در هر خط.
- **فرمان `/fix-bidi`**: متن درهم‌ریخته موجود (چسبانده‌شده یا مسیر فایل) را با همان قواعد اصلاح می‌کند، بدون تغییر معنا.

قواعد را می‌توانید در `hooks/bidi-rules.md` ویرایش کنید؛ نسخه‌ی نصب‌شده پس از Update به‌روز می‌شود.
